# Enclosure CAD Files

3D-printable enclosure for the Smart Laundry Auto-Ordering System, designed in Tinkercad. The enclosure is split into two printable halves.

## Files

| Folder | Contents | Description |
|---|---|---|
| `bottom/` | `bottom.stl`, `bottom_render1.png`, `bottom_render2.png` | Bottom half of the enclosure — houses the ESP32, HX711, and load cell mount |
| `top/` | `top.stl`, `top_render.png` | Top half of the enclosure — cutouts for the OLED display window and tactile buttons |

## Notes

- Files are provided in `.stl` format, ready for slicing and 3D printing.
- Renders (`.png`) show the design from Tinkercad for quick preview without opening a CAD tool.
- Designed in [Tinkercad](https://www.tinkercad.com/).
